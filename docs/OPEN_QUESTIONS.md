# 결정이 필요한 규칙

## 확정됨 (2차 명세)

- 레이어: 0 지상, 1 개미집 / 지형: 흙, 물 / 고체: 토양, 바위 / 수량: 먹이, 유충
- 먹이 + 유충 ≤ 10, 고체 블록은 타일 독점
- 통로: 같은 좌표의 두 레이어를 양방향 연결, 별도 데이터
- 냄새: 종류별 독립 필드(음식, 유충), 흙·물 같은 확산 계수, 고체는 완전 차단, 레이어 간은 통로로만,
  발생량 ∝ 수량, 4방향 확산 → 감쇠 → 발생, 명시적 이산 모델, float 이중 버퍼, 밀폐 경계, 비음수
- 초기값: 틱 0.1s, 확산 0.6/s, 통로 확산 0.6/s, 감쇠 0.025/s, 발생 1.0 농도/s/개

## 확정됨 (3차 명세)

- 확산: 이웃당 교환율 D = 0.6/초, 감쇠: `C *= exp(−k·dt)`, 순서 확산 → 감쇠 → 발생, 모든 계수 설정 가능, 틱 변경 시 안정성 검증
- 편집 모드 / 시뮬레이션 모드 분리: 시작 시 월드 복제, 결과는 원본에 반영 안 함, 재생·일시정지·단일 틱·초기화, 실험 상태 별도 저장
- 고체 배치: 먹이·유충 자동 제거, 고체 교체 가능, 물 → 흙, 원자적, Undo로 전부 복원
- 물 위 고체·통로 → 흙(제거해도 물로 돌아가지 않음)
- 새 월드 기본: 지상 흙/블록 없음, 개미집 흙 + 전부 토양. 빈 월드 생성 유지
- 통로 생성: 지상 중심 고체면 거부, 지상 중심 물 → 흙, 개미집 3×3 고체 제거 + 흙, 통로 1개, 냄새는 중심 좌표로만, Undo 1회. 삭제는 연결만. 3×3이 맵 밖으로 나가면 거부
- 히트맵: 선형 + 자동 최대값 기본, 고정 최대값·로그 전환
- 맵 파일과 실험 상태 파일 분리, 재현성은 같은 빌드·실행 환경 우선
- Undo 최대 256단계 + 메모리 상한, 드래그 1회 = Undo 1단계

## 구현하면서 정한 세부 동작 (확인 필요)

1. **통로 굴착 영역의 먹이·유충** — 개미집 3×3에서 고체만 제거하고 먹이·유충은 남긴다. 지상 중심의 먹이·유충도 남긴다.
2. **이미 있는 통로에 다시 통로 생성** — 굴착 영역이 다시 메워졌으면 다시 굴착한다. 바뀐 것이 없으면 "변경 없음"(Undo 기록 안 함).
3. **통로 중심에 나중에 고체를 놓는 것** — 막지 않는다. 그 동안 통로로 냄새가 이동하지 않는다.
4. **고체가 생긴 칸에 있던 냄새** — 다음 틱에 0이 된다(총량 감소).
5. **메모리 상한을 넘는 단일 편집** — 가장 최근 편집 1개는 상한을 넘어도 유지한다(방금 한 편집은 항상 되돌릴 수 있게).
6. **Undo 메모리 상한 값** — 추정 64MiB(타일 변경 약 280만 건).
7. **실행 중 냄새 종류 구성 변경** — 계수와 틱은 실행 중 변경 가능, 종류 추가·삭제는 새 시뮬레이션에서만.
8. **재생 속도** — ×1, ×2, ×5, ×10, ×50 선택. 계산이 못 따라가면 최대 64틱까지만 따라잡는다.
9. **실험 파일 내용** — 시작 월드와 현재 월드를 모두 저장해, 불러온 실험도 "초기화"로 시작 상태에 돌아갈 수 있다.
10. **편집 모드로 돌아갈 때** — 시뮬레이션 상태는 버려진다(필요하면 먼저 실험 저장).
