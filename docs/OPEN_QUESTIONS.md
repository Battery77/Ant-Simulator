# 결정이 필요한 규칙

## 확정됨 (2차 명세)

- 레이어: 0 지상, 1 개미집 / 지형: 흙, 물 / 고체: 토양, 바위 / 수량: 먹이, 유충
- 먹이 + 유충 ≤ 10, 고체 블록은 타일 독점
- 통로: 같은 좌표의 두 레이어를 양방향 연결, 별도 데이터
- 냄새: 종류별 독립 필드(음식, 유충), 흙·물 같은 확산 계수, 고체는 완전 차단, 레이어 간은 통로로만,
  발생량 ∝ 수량, 4방향 확산 → 감쇠 → 발생, 명시적 이산 모델, float 이중 버퍼, 밀폐 경계, 비음수
- 초기값: 틱 0.1s, 확산 0.6/s, 통로 확산 0.6/s, 감쇠 0.025/s, 발생 1.0 농도/s/개

## 미정 — 현재 구현의 임시 동작과 함께

### 냄새 (Phase 2 시작 전에 필요)

1. **확산 계수 0.6/초의 의미** — (a) 이웃 하나당 교환율: `Δc_i = D·dt·Σ(c_j − c_i)` (한 틱에 이웃마다 6%) 인가,
   (b) 전체 유출률을 4방향에 나눔: 이웃당 D/4 인가? → 계획은 (a). 이때 비음수 조건 `(4·0.06 + 0.06) = 0.30 ≤ 1` 만족.
2. **감쇠 형태** — 명시적 `c ← c·(1 − k·dt)` 인가, 지수 `c ← c·e^(−k·dt)` 인가? → 계획은 명시적(명세의 "명시적 이산 모델"에 맞춤).
3. **고체 블록을 놓은 칸에 있던 냄새** — 즉시 0으로 지우는가(총량 감소)? → 계획은 0으로 지움.
4. **통로 칸 한쪽에 고체가 있을 때** — 통로로 냄새가 이동하지 않는가? → 계획은 양쪽 모두 비고체일 때만 이동.
5. **통로 확산 공식** — `Δc = Dp·dt·(c_반대레이어 − c)` (5번째 이웃처럼 취급)가 맞는가?
6. **실행 중 편집과 Undo** — 시뮬레이션 실행 중 편집을 허용하는가? Undo는 맵만 되돌리고 냄새는 그대로 두는가? → 계획은 둘 다 "예".
7. **히트맵 표시** — 선형/로그 스케일, 최대값 고정/자동 중 무엇인가? → 계획은 자동 최대값 + 선형, 전환 옵션.
8. **저장 범위** — 맵 파일에 냄새 상태·설정도 넣는가, 별도 실험 파일인가? → 계획은 맵(v1)은 그대로 두고 실험 파일을 별도로.
9. **재현성 범위** — 같은 빌드·같은 CPU 아키텍처에서 비트 동일이면 충분한가? (float이므로 OS/CPU 간 비트 동일은 보장하기 어렵다.)

### 편집 규칙 (현재 임시 동작으로 구현됨, 확인 필요)

10. **고체 배치 대상에 먹이·유충이 있으면** — 현재: **거부**. 대안: 덮어쓰기(수량 삭제).
11. **고체 → 다른 고체 교체** (토양 위에 바위) — 현재: **허용**.
12. **물 위의 블록·통로** — 현재: **제약 없음**.
13. **통로 생성 위치 제약** (고체 칸 위 등) — 현재: **제약 없음**.
14. **새 맵 초기 상태** — 현재: 두 레이어 모두 흙, 블록 없음. 개미집 레이어를 토양으로 채워야 하는가?
15. **Undo 기록 상한** — 현재 256단계.
